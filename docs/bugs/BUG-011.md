## Original reproduction and actual behavior

Analyze the first commit of a repository using --commit. Original code always resolved SHA^ and failed because the commit had no parent.

The original observed output is retained in [audit-results-before.json](audit-results-before.json).
The complete runnable scenario is in [audit-repro.py](../../skills/_engine/scripts/audit-repro.py).

## Expected behavior and impact

Analyze initial content as additions relative to an empty tree without inventing a parent commit. The original behavior violated the cited evidence/format contract; priority
reflects the impact on trustworthy Issue or MR analysis. Severity is not an assertion
of remote code execution or an exploitable security vulnerability.

## Implemented correction

Parent IDs are read from the commit object. Root commits use read-only diff-tree --root and base_kind=empty_tree; ordinary and merge commits use their first parent.
