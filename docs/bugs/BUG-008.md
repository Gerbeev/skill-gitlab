## Original reproduction and actual behavior

Import run from .worker in pkg/main.py. Original extraction produced file://worker.py instead of file://pkg/worker.py, leaving the caller unreachable.

The original observed output is retained in [audit-results-before.json](audit-results-before.json).
The complete runnable scenario is in [audit-repro.py](../../skills/_engine/scripts/audit-repro.py).

## Expected behavior and impact

Resolve statically identifiable relative module/package paths; keep unresolved external or ambiguous imports conservative. The original behavior violated the cited evidence/format contract; priority
reflects the impact on trustworthy Issue or MR analysis. Severity is not an assertion
of remote code execution or an exploitable security vulnerability.

## Implemented correction

ImportFrom.level and the containing package determine relative paths. Index refresh selects module.py or package/__init__.py from existing files and preserves original import-target provenance for later file changes.
